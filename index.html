三个知识点

detA=ad−bc

三个知识点

三列向量张成立方体的像

Ap=xAe1+yAe2+zAe3

行列式给出有向体积

detA=Ae1⋅(Ae2×Ae3)

秩给出退化后的维数

rankA=dimspan{Ae1,Ae2,Ae3}

奇异值分解定理 Singular Value Decomposition Theorem

任意 m×n 实矩阵 A 都能分解为下列形式：

A=UΣV⊤

U 和 V 分别是 m 阶和 n 阶正交矩阵，满足 U⊤U=Im、V⊤V=In。 Σ 是 m×n 矩阵，主对角线有 p=min(m,n) 个元素。

U= ( u11⋯u1m ⋮⋱⋮ um1⋯umm )
Σij= { σii=j 0i≠j
V= ( v11⋯v1n ⋮⋱⋮ vn1⋯vnn )

主对角线元素是 A 的奇异值，满足 σ1≥⋯≥σp≥0。

从右往左，V⊤ 把输入转到右奇异向量坐标，Σ 按各轴缩放，U 把结果送到左奇异向量方向。

  • 当 1≤i≤p 时，Avi=σiui，其中 ui 与 vi 分别是 U 与 V 的第 i 列。
  • 秩等于正奇异值的个数。
  • 对方阵，|detA| 等于全部奇异值之积。
